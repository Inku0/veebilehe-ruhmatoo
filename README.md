# veebilehe-ruhmatoo
Veebilehe rühmatöö on koostööülesanne ehitada algusest peale valmis üks lihtne veebileht. Tehniliste oskuste omandamiseks toimuvad vastava sisuga seminarid. Veebilehe sisu teema on vabalt valitav. See võib olla lehekülg tutvustamaks hobi või kodulooma; spordivõistkonda või kuulsust; jutustada lugu või õpetada midagi kasulikku.

Miinimumnõuded hindamisele pääsemiseks:

- Kasutada versioonihaldustarkvara Git
- Projekt on avalikult kättesaadav repositooriumis (Github, Bitbucket vmt)
- Valmis projekt on üleval kodu.ut.ee lehel
- Kasutusel on HTML, CSS
- Leht on ehitatud puhta HTMLi ja CSSiga, pole kasutatud valmis raamistikke (bootstrap jne)


Projekti wiki Githubis vms keskkonnas sisaldab:

- Mida veebileht tutvustab või mis on selle lehe eesmärk?
- Kes on tiimiliikmed?
- Milline on tiimisisene tööjaotus?
